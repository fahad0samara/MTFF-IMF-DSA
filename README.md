# منظومة التخطيط المالي متوسط الأجل وديناميكيات الدين العام
## Medium-Term Fiscal Framework (MTFF) & Sovereign Debt Dynamics Dashboard

منظومة محاكاة وتحليل مالي سيادي متقدمة تعتمد على معايير **صندوق النقد الدولي لإطار استدامة الدين (IMF Debt Sustainability Analysis - DSA)** وإطار التخطيط المالي متوسط الأجل (**MTFF**)، مصممة لوزارات المالية والمؤسسات المالية والمحللين الاقتصاديين.

---

### 📌 اسم المشروع (Project Name)
- **بالعربية:** منظومة التخطيط المالي متوسط الأجل وديناميكيات الدين العام الحكومي (MTFF & IMF DSA)
- **بالانجليزية:** Sovereign MTFF & Debt Dynamics Simulator (Medium-Term Fiscal Framework Dashboard)

---

### 📝 الوصف التعريفي (Description)
منصة ويب تفاعلية متكاملة باللغة العربية والإنجليزية، تدعم التحليل المالي وتوقعات الاقتصاد الكلي لـ 8 اقتصادات سيادية (المملكة العربية السعودية، دولة الإمارات العربية المتحدة، جمهورية مصر العربية، الولايات المتحدة، ألمانيا، اليابان، المملكة المتحدة، والمملكة المغربية). 

تتيح المنظومة للمسؤولين وصناع القرار المالي ضبط مؤشرات الاقتصاد الكلي والسياسة الضريبية وهيكل الإنفاق العام والأسقف الاحترازية عبر مقابض تفاعلية لحظية، مع محاكاة مسار الدين العام ونسبة الدين إلى الناتج المحلي الإجمالي ($Debt/GDP$)، وتوليد مروحة احتمالات المخاطر (Fan Chart)، واختبارات الإجهاد (Stress Testing)، واحتساب الاحتياجات التمويلية الإجمالية (Gross Financing Needs - GFN)، وتصدير تقارير رسمية شاملة بصيغة PDF وتصدير الجداول بصيغة CSV.

### ✨ أبرز المميزات والوظائف الرئيسية

1. **دعم التغطية المتعددة للدول السيادية (Multi-Country Profiles):**
   - بيانات اقتصادية وتاريخية حقيقية مستندة إلى قاعدة بيانات آفاق الاقتصاد العالمي التابعة لصندوق النقد الدولي (**IMF World Economic Outlook - WEO**).
   - التبديل الفوري بين الدول بما يشمل العملة المحلية وسعر الصرف والهياكل الضريبية (ضريبة القيمة المضافة، ضريبة الشركات، والجمارك).

2. **محرك المحاكاة اللحظي (Interactive Macro & Fiscal Simulator):**
   - **مؤشرات الاقتصاد الكلي:** نمو الناتج الحقيقي، التضخم ومخفض الناتج، أسعار الفائدة السيادية، ومعدل تغير سعر الصرف.
   - **السياسة الضريبية:** معدل ضريبة القيمة المضافة / الاستهلاك، ضريبة أرباح الشركات، كفاءة التحصيل والفوترة الإلكترونية، ونمو الإيرادات غير الضريبية والنفطية.
   - **هيكل الإنفاق العام:** أجور وتعويضات العاملين بالقطاع العام، المنافع الاجتماعية والإعانات، والإنفاق الرأسمالي والاستثماري ومضاعف النمو المالي.
   - **الأسقف والقواعد المالية:** تحديد سقف الدين المستهدف وسنة الالتزام بالانضباط المالي.

3. **حزمة الرسوم البيانية والتحليلات المتخصصة وفق معايير صندوق النقد الدولي (DSA):**
   - **مقص المالية العامة (Fiscal Scissors):** مقارنة تطور الإيرادات الكلية مقابل النفقات الكلية ورصد نقطة التوازن المالي.
   - **تفكيك الإيرادات والضرائب (Tax Breakdown):** بيان الحصيلة بين القيمة المضافة، وأرباح الشركات، والجمارك، والموارد السيادية مع قياس مرونة التحصيل (Tax Buoyancy).
   - **مروحة احتمالات مسار الدين (Debt Fan Chart):** محاكاة النطاقات الاحتمالية (10% إلى 90%) لمسار الدين العام حتى 2032.
   - **شلال ديناميكيات الدين (Debt Dynamics Waterfall):** تفكيك التغير التراكمي في نسبة الدين إلى: العجز الأولي، أثر كرة الثلج $(r - g)$، وأثر تقلبات سعر الصرف الأجنبي.
   - **مصفوفة اختبارات الإجهاد (Macro Stress Testing Matrix):** جدول ثنائي الأبعاد يقيس مناعة الدين تجاه صدمات متزامنة في النمو وأسعار الفائدة.
   - **الاحتياجات التمويلية الإجمالية (GFN Profile):** تفصيل أقساط سداد أصل الدين وتمويل العجز مع فحص عتبات مخاطر السيولة.
   - **مؤشرات الموقف المالي المتقدمة:** الرصيد الأولي المثبت للدين ($p^*$)، الميزان الأولي المعدل دورياً ($CAPB$)، والحافز المالي ($Fiscal\ Impulse$).

4. **إعداد وتصدير التقارير الرسمية (Reporting & Data Export):**
   - **تقرير استراتيجي وزاري بصيغة PDF:** وثيقة جاهزة للطباعة والتصدير باللغة العربية تشمل الملخص التنفيذي، وجدول MTFF، وتقييم الملاءة والاستدامة، والتوصيات السياساتية.
   - **جدول البيانات المالية وتصدير CSV:** تصفح وتنزيل الجداول المالية بالكامل (2024–2032) بترميز UTF-8 المتوافق مع برامج الجداول الإلكترونية.
   - **نافذة توثيق مصادر البيانات (IMF Provenance):** مراجع البيانات الصادرة عن صندوق النقد الدولي ومواصفات معادلات استدامة الدين.

5. **تصميم عصري متجاوب بالكامل (Responsive & Mobile-First):**
   - متوافق مع كافة أحجام الشاشات (الهواتف الذكية، الأجهزة اللوحية، والشاشات المكتبية العريضة).
   - واجهة مستخدم مصممة وفق أحدث معايير تجربة المستخدم باللغة العربية (RTL) مع خطوط *IBM Plex Sans Arabic* و*Cairo*.

### 🛠️ التقنيات المستخدمة (Tech Stack)

- **واجهة المستخدم:** React 19، TypeScript، Tailwind CSS v4.
- **الرسوم البيانية التفاعلية:** مكونات مخصصة مبنية باستخدام Pure SVG و CSS حديث لضمان أعلى أداء واستجابة لحظية دون بطء.
- **الأيقونات والتنسيق:** Lucide React.
- **بيئة التطوير والتشغيل:** Vite 8، Node.js Express.

### 🚀 خطوات التشغيل محلياً (Getting Started)

1. **تثبيت الحزم البرمجية:**
   ```bash
   npm install
   ```

2. **تشغيل الخادم المحلي للتطوير:**
   ```bash
   npm run dev
   ```
   سيتم تشغيل التطبيق محلياً عبر الرابط: `http://localhost:3000`

3. **بناء النسخة الإنتاجية:**
   ```bash
   npm run build
   ```

4. **فحص الأنواع البرمجية (Linting):**
   ```bash
   npm run lint
   ```
